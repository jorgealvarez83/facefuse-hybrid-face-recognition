## 🔧 Troubleshooting

### Common Issues and Solutions

**Problem: Application won't start**
- Make sure you extracted ALL files from the ZIP.
- Check that your Windows is updated.
- Temporarily disable antivirus software and try again.

**Problem: Slow performance**
- Close other programs while using FaceFuse.
- Reduce image size before uploading.
- Restart the application if it becomes unresponsive.

**Problem: No faces detected**
- Ensure images are clear and well-lit.
- Use photos where faces are visible and not obscured.
- Try closer, front-facing shots.
